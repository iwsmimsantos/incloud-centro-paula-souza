# Nome do Projeto: Incloud

## Nome do Grupo: Inclouders


Esta documentação está organizada em diferentes arquivos conforme apresentado abaixo.

### Gestão do Projeto

- **[GestaoProjeto.md](https://github.com/Inteli-College/2025-1A-T13-ES05-G03/blob/main/documentos/GestaoProjeto.md)**: Este documento acompanha e mapeia o desenvolvimento do projeto ao longo de todas as sprints. Ele inclui informações sobre o backlog, análise de desempenho, riscos identificados, mitigação de riscos e uma análise post mortem com lições aprendidas e oportunidades de melhoria.

### Processo de Desenvolvimento de Software

- **[GestaoConfiguracao.md](https://github.com/Inteli-College/2025-1A-T13-ES05-G03/blob/main/documentos/GestaoConfiguracao.md)**: Define as diretrizes para o fluxo de trabalho no desenvolvimento do projeto, incluindo políticas de branches (Gitflow), commits, push e pull requests. O objetivo é garantir entregas consistentes e minimizar erros.

- **[GuiaPadroesDesenvolvimento.md](https://github.com/Inteli-College/2025-1A-T13-ES05-G03/blob/main/documentos/GuiaPadroesDesenvolvimento.md)**: Apresenta padrões de codificação e práticas de desenvolvimento para garantir qualidade e consistência no código. Inclui convenções de nomenclatura, formatação de código, comentários, arquitetura de software e testes automatizados.

### Desenvolvimento do Produto

- **[Projeto.md](https://github.com/Inteli-College/2025-1A-T13-ES05-G03/blob/main/documentos/Projeto.md)**: A documentação principal do projeto, contendo requisitos, personas, jornadas, diagramas UML, modelagem BPMN e diversos outros artefatos essenciais para o desenvolvimento do produto.

- **[Manual-Instalacao.md](https://github.com/Inteli-College/2025-1A-T13-ES05-G03/blob/main/documentos/Manual-instalacao.md)**: Explica como montar, conectar e utilizar o protótipo, fornecendo orientações para a instalação e configuração do sistema.
