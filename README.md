## 📝 Descrição

<p align="justify">
Projeto de sistemas distribuídos desenvolvido para o Centro Paula Souza, com o objetivo de mapear, em um banco de dados, alunos com necessidades especiais e direcioná-los aos profissionais adequados por meio de uma aplicação web. Para isso, utiliza-se uma infraestrutura em nuvem para armazenar e gerenciar as informações, possibilitando o registro e a consulta de históricos de atendimento. Dessa forma, o processo, que hoje é conduzido em planilhas, torna-se mais eficiente, centralizado e fácil de administrar.
</p>

## 💻 Como Utilizar a Aplicação


1. Acesse a aplicação através do link do frontend
2. Faça login com suas credenciais institucionais
3. Na plataforma, você poderá:
   - Cadastrar e gerenciar alunos com necessidades especiais
   - Adicionar novos profissionais ao sistema
   - Monitorar atendimentos em tempo real
   - Gerar e exportar relatórios em PDF
   - Visualizar histórico de acompanhamentos
   - Agendar novos atendimentos
   - Consultar dados estatísticos

Não é necessário instalar nenhum software adicional. A aplicação é acessível via navegador web em qualquer dispositivo com conexão à internet.

## 🛠️ Configuração para desenvolvedores

Se você é um desenvolvedor e deseja contribuir ou trabalhar com o código do projeto Incloud, siga as instruções abaixo:

### Requisitos Prévios

- [Git](https://git-scm.com/downloads)
- [Node.js](https://nodejs.org/) (versão 16.x ou superior)
- [npm](https://www.npmjs.com/) ou [Yarn](https://yarnpkg.com/)
- Editor de código (recomendamos [VS Code](https://code.visualstudio.com/))

### Configuração do Ambiente

1. Clone o repositório:
   ```bash
   git clone https://github.com/Inteli-College/2025-1A-T13-ES05-G03.git
   cd 2025-1A-T13-ES05-G03
   ```

2. Instale as dependências:
   ```bash
   # Na pasta raiz do projeto
   cd src/backend
   npm install
   
   # Para o frontend
   cd ../front
   npm install
   ```

3. Configure as variáveis de ambiente:
   - Crie um arquivo `.env` na pasta `src/backend` com informações de conexão com o banco de dados.

4. Inicie o servidor de desenvolvimento:
   ```bash
   # Backend
   cd src/backend
   npm run dev
   
   # Frontend (em outro terminal)
   cd src/front
   npm start
   ```

5. Acesse a aplicação em desenvolvimento:
   - Frontend: `http://localhost:4200`
   - Backend: `http://localhost:3000`

### Estrutura do Projeto

- `src/backend`: Código do servidor Node.js com Express
- `src/frontend`: Aplicação Angular
- `src/database`: Scripts SQL e migrações
